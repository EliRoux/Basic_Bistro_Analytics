# SQL Analysis

This folder contains SQL scripts used for the Basic Bistro analytics project.

## Purpose

SQL will be used to:

- Query the PostgreSQL database
- Clean and transform data
- Aggregate sales information
- Analyse product performance
- Analyse revenue trends
- Identify peak trading periods
- Calculate business metrics
- Prepare datasets for Power BI
- Support Python-based analysis

## Planned SQL Workflow

Raw GAAP data
↓
PostgreSQL tables
↓
Data validation
↓
SQL transformations
↓
Analytical queries
↓
Power BI / Python

## Planned Query Categories

### Data Validation
Queries used to identify:

- Missing values
- Duplicate records
- Invalid dates
- Unexpected values
- Referential integrity issues

### Sales Analysis

Queries examining:

- Revenue
- Transactions
- Average transaction value
- Product sales
- Category performance

### Time Analysis

Queries examining:

- Daily performance
- Weekly performance
- Monthly performance
- Day-of-week trends
- Hourly trends

### Product Analysis

Queries examining:

- Best-selling products
- Low-performing products
- Product revenue
- Product quantity
- Category performance

### Business Insights

Queries designed to support actionable recommendations for management.

## Important

The database schema will be designed after the GAAP export format has been inspected.

No assumptions should be made about available fields until the source data has been reviewed.
